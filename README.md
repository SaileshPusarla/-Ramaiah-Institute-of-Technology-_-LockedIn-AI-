Samsung PRISM Hackathon

LockedIn AI - Intelligent Student Productivity Assistant

**PRODUCT STATEMENT**
Students struggle with:
1) Managing tasks
2) Prioritizing exams
3) Summarizing lengthy notes
4) Dynamically adjusting study schedules

**OUR SOLUTION**
LockedIn AI provides:
· AI-powered timetable generation
· Dynamic study-plan adjustment
· Intelligent academic Q&A
· Document summarization
· Task tracking with adaptive scheduling

**FEATURES**
• Task Memory Layer
• Planning Engine
• Interactive Reasoning Module
• Knowledge Processing Module
• Dynamic Plan Updates
• Local LLM Integration
• Real-time AI Query Handling

**TECH STACK**
Frontend:
- HTML
- CSS
- JavaScript
AI:
- Ollama
- Qwen2.5:3B
Runtime:
- Local AI inference

**SETUP**
1. Install Ollama
2. Run: ollama pull qwen2.5:3b
3. Run: ollama serve
4. Open index.html in browser

**USAGE**
- Add tasks
- Generate plans
- Update plans
- Upload notes
- Summarize notes
- Doubts can be asked
